# @useless-engineer/utils

Small, typed utilities from [@useless_engineer.dev](https://www.instagram.com/useless_engineer.dev/).
One package, multiple entry points, so React Native code never pulls in what it doesn't use.

```ts
import { debounce, throttle } from "@useless-engineer/utils";
import { isIOS, isAndroid } from "@useless-engineer/utils/react-native";
```

`react` and `react-native` are optional peer dependencies.
